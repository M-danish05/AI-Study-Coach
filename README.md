#  AI Study Coach

A smart, single-file web application that helps students study more effectively using AI-powered personalized study plans, interactive quizzes, and progress tracking.



##  Features

-  Personalized Study Plan based on your subject and weak topics
-  Interactive Quiz with instant feedback and explanations
-  Visual Progress Tracker with animated progress bars
-  Smart Study Tips personalized to your subject
-  Clean dark-themed landing page
-  Fully responsive — works on mobile and desktop
-  No backend required — runs entirely in the browser



## How to Use

1. Download the `AI study coach.html` file
2. Open it in any browser (Chrome, Firefox, Edge)
3. Enter your subject and weak topics
4. Click **Generate My Study Plan**
5. Get your personalized plan, take a quiz, and track your progress!



## Notes

- No installation required
- No internet connection needed
- Works on any modern browser
- Single file — easy to share and deploy
